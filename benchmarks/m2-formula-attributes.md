# Formula attribute save/reload compatibility

probe_formula_attributes.py compares newly assigned native and openpyxl 3.1.5 data-table records through public save/reload calls. All properties agree: newly assigned false flags reload as booleans, true serialized flags as source strings, and omitted empty input strings as None. Raw results: results/m2-formula-attributes-interop.json. Original "0"/"false" flag spellings and explicit RetainExplicit behavior have separate deterministic writer tests; repeated editor saves share that policy.

Shared/normal read trend: one warmup and five rotating cold-process samples, each native verifies all expressions and caches; public cache verification is separate and untimed. No temporary storage is used.
