# ADR 0040: Canonical owned temporal assignment

Core CellValue.temporal_value() supplies the shared literal/formula-cache interpretation. StyleRegistry resolves temporal assignment by preserving any existing date/duration code or interning a default code and borrowed-key format variant. TemporalStyleIds and register_temporal_presets_with_limit() centralize preset creation and kind mapping, retaining source component IDs. The XLSX writer uses these methods instead of maintaining a parallel preset-registration algorithm. Source catalogs retain their original identities; automatic default catalogs retain datetime/time/duration/date IDs 1/2/3/4.

An owned Workbook's WorksheetEditor.set()/append() now resolves temporal cell style IDs before committing cell values. Imported date-format zero remains zero. The bank initializes default styles lazily at its first temporal assignment, including canonical presets shared by ordinary default-writer output. Immutable catalog views immediately expose the assigned code and component references. Standalone Worksheet is still a raw model without a workbook catalog; it retains caller IDs and does not invent an independent style bank.

Mutation preflight accounts for the prospective cell payload before allocating styles. The facade borrows the workbook's optional registry alongside one sheet, with a joint allowance excluding other sheets, slot storage and theme. Every derived record reduces the sheet's remaining aggregate allowance. Four stack slots deduplicate kind preparation within one append without a retained cache. Prepared cells move into their sheet and consuming export transfers its registry; no complete appearance/catalog clone or second row-value vector is added.

Cell/count/range preflight failures leave cells and styles unchanged. If later multi-kind style registration fails, no row cells or append cursor are committed, but earlier valid interned styles/codes and accounted reservation capacity may remain reusable. Fresh candidate-registry initialization failures publish no registry. Dropping the mutation facade restores the sheet's personal configured ceiling, with aggregate allowance recomputed on each new borrow. Explicit raw Cell replacement continues honoring the caller's chosen base StyleId; adapters must carry the existing style when assigning a new value, as required by their public API.

Deterministic tests cover pre-save getters, four kinds, repeated shared identities, component sharing, retaining different temporal formats, formula caches, default/source zero, standalone distinction, combined cell/style limits and failed multi-kind append/retry. Native/public owned and separate streaming output comparisons verify every value/type/code/font/fill/border/alignment across two sizes. See benchmarks/m4-owned-temporal-styles.md.

Borrowed write_workbook() checks any owned catalog against the writer's catalog before output. Identical catalogs, including lazily initialized default temporal presets, support repeated borrowed saves without a catalog clone. Mismatched arbitrary styled banks still require ownership transfer; they do not silently reinterpret IDs.

This closes temporal value assignment within owned banks, not complete public style mutation, loaded lazy ownership, repeated non-consuming arbitrary styled save, source feature graphs or milestones M2/M4/M5. Python remains a pinned adapter; general style object setters/getters are separate work.
