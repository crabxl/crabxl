# ADR 0041: Literal shared-formula group identities

SharedFormulaIndex distinguishes Missing, canonical Numeric(u32) and Literal(Arc<str>). Compatible source semantics use exact decoded spelling: absent si differs from an empty attribute, and 01/+1/1 remain separate identities. Larger decimals and opaque strings are supported. Only canonical unsigned u32 spellings use the allocation-free numeric path; numeric hashing retains the prior u32 hash input. FormulaType is Clone rather than Copy because it can own a shared source identifier; numeric Rust constructors use index.into().

The worksheet template map uses this same canonical key. A literal key and its master metadata share one immutable allocation, and followers intern their metadata against the retained template key. No worksheet materialization, second identity map or retained per-follower string is added. Decoded opaque headers can need transient allocations before interning. Numeric paths retain no strings. Template estimates include actual key shape, string bytes and the shared ownership header; per-value metadata estimates conservatively charge shared payloads when another owner retains the same allocation.

Strict ValidateGroups keeps required u32 schema validation and geometry/group checks. Missing/opaque/overflow IDs return contextual errors. Compatible projected reads retain required masters and use the same exact identity semantics. Data-only value projection keeps its separate semantics. Writer preflight validates literal XML characters before row bytes/style derivation; unresolved literal records escape attributes, while ordinary nonempty shared expressions continue expanding into normal output.

Tests cover numeric allocation behavior, missing/empty distinction, spelling equality, shared Arc ownership, metadata accounting, streamed/projected/materialized reads, strict error context and invalid writer retry. Fifteen public source cases match pinned openpyxl loading and caches, using generated OOXML/public calls without implementation inspection. No complete shared-group editing or full formula API is claimed.

The key's larger fixed representation raises the single numeric template estimate from 355 to 419 bytes. The escaped literal feature case adds 29 bytes to 448. Benchmarks disclose time/RSS tradeoffs in benchmarks/m2-shared-indices.md. This checkpoint does not complete M2.
