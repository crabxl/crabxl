# ADR 0042: Canonical worksheet viewport metadata

Select the pinned rust_xlsxwriter worksheet view, pane and selection composition/XML helpers rather than importing its workbook engine. Core owns SheetViews, SheetView, Pane, Selection and typed pane/state/view enums. XLSX owns codecs and I/O. Expand the upstream subset to baseline public worksheet-view attributes, source-ordered multiple views/selections and literal origins/ranges. Attributes borrow payloads and numeric formatting writes directly; no per-attribute String or vector of cloned attributes is retained.

Public openpyxl 3.1.5 probes determine defaults and freeze behavior. B3 freezes one column/two rows, adds top-right/bottom-left selections with absent cell/range attributes and retains the existing primary selection. Clearing freezes retains selections. Source loading supplies A1 selection defaults when attributes are absent, and empty containers/no selections acquire descriptor defaults. Explicit empty model lists remain writable. Fractional/negative finite splits and unrestricted i64 zoom/integer fields are retained; nonfinite splits reject instead of writing the reference's invalid empty split attribute. Integers outside i64 and typed extensions remain open.

Owned worksheets allocate no view model unless explicitly assigned. Setters validate and charge wrapper/actual vector capacities, nested boxes and string payloads before mutation. Structural recounts retain view charges; intentional sheet copying clones view data and preflights aggregate limits. The workbook mutation facade uses the same setter and shared remaining allowance.

Reader.sheet_views scans a bounded decompressed header, stops at the view container or sheetData and returns owned metadata without reading cells. The unconsumed XML and ZIP CRC are not verified. Views must precede sheetData according to schema order; full malformed/out-of-order-source compatibility remains open. Retained records/capacities and transient parser/input buffers are separate resource costs. Source extensions reject typed reads/replacement instead of silently disappearing; unchanged original-package saves retain them.

Writer.start_sheet_with_views borrows settings, validates all literal XML characters and finite splits, and encodes a bounded header before closing the previous sheet or creating a new spool. Actual scratch capacity participates in metadata preflight. The existing static-header numeric path is retained. Owned worksheet export calls this same codec; no second feature engine is added.

Original-package view overlays share the cell-overlay byte cap and automatic memory policy. Source header validation uses remaining retained operation allowance while parser space has its existing working reserve. Saves borrow the overlays, stream affected XML to EOF and replace views with an explicit transitional/Strict namespace. Unrelated parts remain compressed copies. Pure view edits do not invalidate formula caches or discard calculation chains; mixed value/view edits keep the existing global recalculation policy. Signed packages and unknown source view extensions reject modification. No new worksheet spool is added to this editing path.

Deterministic tests cover creation/readback, defaults, multiple views/selections, finite and XML failures, atomic budget rejection, structural recount/copy, Strict prefixed namespaces, repeated/mixed saves, cache preservation and cleanup. Public feature checks and serial release measurements are recorded in benchmarks/m5-worksheet-views.md. This is a coherent selected-module M5.2 checkpoint, not M5 completion or complete loaded-workbook graph support.
