# ADR 0043: Canonical printing metadata and bounded worksheet tails

Select pinned rust_xlsxwriter print-option, margin, page-setup and row/column-break XML layouts into the existing core/XLSX architecture. Core owns typed printing options, margins, setup enums/literal dimensions, pageSetUpPr flags and sparse break records. XLSX borrows payloads and writes numeric attributes directly. Public openpyxl 3.1.5 probes expand the upstream subset to all baseline field names, optional false/default distinctions, literal paper-dimension prefix spelling and computed break counts. Break coordinates retain optional None and acquire source defaults on load; literal none page tokens map to absent enum values. The public manualBreakCount counts all records, including false manual flags. Nonfinite margins reject rather than writing the reference's invalid empty attributes. Integer fields use i64; broader descriptor/invalid-schema coercions remain open.

PrintSettings is optional boxed metadata in the same sparse Worksheet; unchanged unconfigured sheets allocate nothing new. Replacement validates before mutation and charges the fixed box, actual break vector capacities and literal payloads. Aggregate workbook mutation/copy and structural recount use the same model. Views and printing export through one writer start_sheet_with_settings API; no second engine or upstream public types are exposed.

Printing XML follows sheetData, so Reader.print_settings scans and decompresses through EOF/CRC without retaining cells or the worksheet XML. Resource limits separately bound raw part bytes, event/input buffers and retained metadata. This is bounded RAM with linear source I/O, not an indexed random-access read. Generalized worksheet metadata attribute decoding is shared with the view codec. Namespace resolution identifies office relationship IDs for pageSetup as well as sheet catalog entries.

Creation prevalidates XML/finite values and encodes a bounded header/footer pair. Actual combined buffer capacities participate in metadata admission before closing the previous sheet or creating its successor spool. Only the encoded footer transfers into ActiveSheet; per-row temporary/part checks reserve its actual length. Closing writes and releases it. Default numeric sheets retain static headers/footers. Footer-size/metadata failures leave the old active sheet usable, and normal finish/abort retains existing cleanup semantics.

Original-package printing overlays share aggregate byte/Auto allowance with value/view overlays. View/printing models are boxed in the part map, avoiding large inline model slots in sparse BTree nodes; a conservative 1,024-byte per-part node allowance supplements key/model payloads. Source validation budgets against the larger live/prospective overlay charge, so shrinking replacements do not accidentally borrow memory still held by old overlays. Source printing metadata is verified under remaining retained space before replacement. Changed printing streams the affected worksheet to EOF and preserves unrelated sheet properties, header/footer, extension/binary parts and their package identities. Replacement writes page properties inside the original sheetPr or inserts a new one; page setup stays before header/footer, and breaks stay after it and before later tail nodes. Transitional/Strict namespace context is explicit. Pure printing changes retain formula caches/calculation chains; mixed value changes keep global recalculation rules.

An imported printer relationship ID can be read and retained, together with unchanged printer binary/relationships. New-package printer links and changed IDs reject until relationship graph mutation is implemented. This does not validate or repair pre-existing dangling printer targets. Signed packages and unknown printing extensions reject modification. Print areas/titles, new/edited header-footer content, full sheet properties and protection remain open.

Generated deterministic/public fixtures test every field, defaults, sparse break order/count, literal dimension handling, owned copy/recount/aggregate failure, combined views/printing, repeat/mixed save, source properties/header-footer ordering, printer identity/binary preservation, invalid XML/nonfinite settings and bounded footer failure/cleanup. Serial release evidence and default numeric regression are recorded in benchmarks/m5-printing.md. This coherent module checkpoint does not complete M5.7, M5 or loaded-workbook graph support.
