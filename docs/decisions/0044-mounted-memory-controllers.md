# ADR 0044: Mounted Linux memory controllers

Automatic availability discovery resolves the process memory controller through /proc/self/cgroup and /proc/self/mountinfo. Cgroup v1 memory membership takes precedence in a hybrid layout; otherwise the unified v2 membership is used. Mount roots map absolute membership paths to visible mount directories, including bind mounts and mountinfo space/tab/newline/backslash escapes. A namespace-reported mount root /.. with process membership / inspects only the visible mounted root, without filesystem parent traversal; stricter hidden descendant constraints cannot be observed. Multiple matching visible aliases must all be readable and their minimum headroom is used. Prefix matching uses path components, not raw strings.

The existing ancestor walk is shared between v1 memory.limit_in_bytes/memory.usage_in_bytes and v2 memory.max/memory.current. Finite limits subtract current usage with saturation; v2 max and v1 numeric unlimited sentinels remain compatible with host availability. V1 ancestor checks are conservative even on non-hierarchical legacy mounts. Missing usage for a finite limit, malformed data, unsupported path encoding or unresolved mounts triggers conservative fallback. Caller availability and explicit budgets bypass probing and keep their existing priority.

The resulting operation allowance remains a snapshot, not a reservation or hard RSS ceiling. Visible ancestors can be examined; limits and competing usage above a hidden bind-mount root cannot be fully observed. Non-Linux native probes, concurrent strategies and complete Auto catalog tuning remain staged. This checkpoint does not close M2 or M7.

Deterministic fixtures verify legacy/hybrid controllers, visible parent pressure, exhausted limits, numeric unlimited limits, missing usage, mount roots, escaped paths, aliases and malformed inputs. Workspace tests, rustfmt and Clippy pass. benchmarks/m2-cgroup-discovery.md records serial current/prior native and public reference workloads, their checksums, Auto decisions, RSS and temporary storage. The live measurement host uses cgroup v2; actual v1-host performance is not claimed. No upstream source was copied for this platform probe.
